Contact ZemTools

Use the ZemTools project issue tracker to report a problem, suggest a new utility, or request a correction. This is the current public feedback channel for the website.

Report a bug or calculation problem

Open ZemTools Issues on GitHub

When reporting a problem, include the name of the tool and the page address, the steps that led to the problem, the units you selected, the result you expected, and the result you received. For a calculation or conversion issue, include a simple example that can be checked without exposing personal information.

For technical problems, also mention your device, operating system, and browser. Screenshots can help when they do not contain private information.

Suggest a correction or a new tool

For a correction, explain which label, formula, conversion, instruction, or result appears incorrect. Where relevant, include a reliable reference or standard that supports the suggested correction.

For a new tool idea, describe the task you are trying to complete, the information you would enter, and the result or output that would make the tool useful. Clear examples help us understand the request.

Important privacy note

GitHub Issues are part of a public repository and submissions may be visible to other people. Do not include passwords, payment details, identity documents, private contact information, confidential project details, or other sensitive personal information. Use sample values instead of real private data.

Submitting an issue may require a GitHub account. ZemTools does not currently publish a separate private support email or promise a particular response time. Feedback is reviewed as the project allows.
