# Utility Platform — Master Design Reference

## Status
**Current Master — LOCKED**

The **Significant Figures Calculator** (`calculator.html`) is the official visual reference for all Utility Platform tool pages.

The locked system defines the approved blue/white desktop and mobile language: header/navigation, search/menu controls, breadcrumbs, hero/title treatment, cards, form controls, buttons, results, educational sections, FAQ, responsive behavior and centered footer.

## Architecture
`master-tool-design.css` is the shared visual foundation. Page-specific CSS must be narrowly scoped to the tool's unique UI. Broad emergency overrides are not allowed.

## Related Tools
`master-related-tools.css` is only for genuinely related tools. Empty space is preferable to unrelated links.

## Functionality
Rebuilds preserve original calculation logic, URLs, SEO metadata and core functionality.
