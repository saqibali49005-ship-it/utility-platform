What are Significant Figures?

Significant figures are the digits in a number that communicate meaningful measurement precision. They help show how precisely a value is known.

Rules Summary

  • For addition and subtraction, round to the least precise decimal place.
  • For multiplication and division, round to the fewest significant figures.
  • Non-zero digits and interior zeros are significant.
  • Leading zeros are not significant.
  • Trailing decimal zeros are significant; whole-number trailing zeros can be ambiguous without notation.

Examples

12.3 + 4.56 = 16.9  (3 s.f.)
5.2 × 3.1 = 16  (2 s.f.)
100.0 ÷ 3.00 = 33.3  (3 s.f.)
0.00450 × 2.0 = 0.0090  (2 s.f.)

How to Use a Significant Figures Calculator

A significant figures calculator helps you count meaningful digits, round a number to a chosen precision, and apply measurement-precision rules to arithmetic. Enter the value as written, including its decimal point or scientific notation, so its intended precision is clear.

How to round to significant figures

  1. Start at the first non-zero digit. This is the first significant digit.
  2. Count the required number of significant digits from left to right.
  3. Look at the next digit: if it is 5 or greater, increase the last kept digit by one; otherwise leave it unchanged.
  4. Use decimal places or scientific notation to make the final precision unambiguous.

For example, 0.004567 rounded to 3 significant figures is 0.00457. The leading zeros locate the decimal point; they do not count as significant digits.

Significant figures in addition and subtraction

For addition and subtraction, the result is limited by the input with the fewest decimal places. For example, 12.11 + 18.0 = 30.11, which is reported as 30.1 because 18.0 is precise only to the tenths place.

Significant figures in multiplication and division

For multiplication and division, report the result with the same number of significant figures as the input with the fewest significant figures. For example, 2.50 × 4.0 = 10.0 before rounding, so the reported result is 1.0 × 10¹ (2 significant figures), which makes the precision clear.

Zeros and scientific notation

  • Leading zeros are not significant: 0.0032 has 2 significant figures.
  • Zeros between non-zero digits are significant: 1002 has 4 significant figures.
  • Trailing zeros after a decimal point are significant: 4.500 has 4 significant figures.
  • Scientific notation makes precision explicit: 1.20 × 10³ has 3 significant figures.

Exact counted quantities and defined conversion factors do not limit significant figures in the same way as measured values. Keep unrounded digits during intermediate steps and round the final answer once.
