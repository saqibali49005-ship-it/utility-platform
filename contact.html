Contact Utility Platform

For now, the best way to report a bug, suggest a tool, or request a correction is through the project's public GitHub repository.

Report a problem or suggestion

Open an issue on GitHub

GitHub Issues is the current development-stage contact method. A dedicated contact method may be added before the public launch.

What to include

  • The tool or page you were using
  • The input you entered (do not include private or sensitive information)
  • The result you expected
  • The result you received
  • Your device/browser if the problem is technical

Do not submit passwords, payment information, identity documents, or other sensitive personal information in a public issue.
